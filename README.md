# ETL производственной деятельности мясокомбината 🍖

## Обзор 📘

ETL процесс для загрузки данных в базу данных clickhouse с последующей визуализацией в Apache Superset.

## Инфра 🖥-🖥-🖥

В данном проекте в докере настроен запуск следющих сервисов:
- Flask-сервер на Python для раздачи файлов
- Apache Airflow
- Clickhouse
- Apache Superset

## ETL 🏭

Каждую неделю в пятницу (по идеи) сотрудники какой-то организации загружают на Flask-сервер весь Excel файл. Далее из этого файла выбираются только записи за последнюю неделю. Они же перекладываются в clickhouse, а затем Superset ходит туда и обновляет дашборды.

Чтобы проделать это локально: поднять инфру (см ниже), зайти на Flask-сервер (localhost:47900/upload), загрузить файл через форму, перед этим ознакомьтесь, какие колонки должны быть файле. Тут вы исполняете роль сотрудника организации. Далее зайдите в Airflow (localhost:8080), креды - airflow/airflow, запустите даг вручную. Потом можете подключится к Clickhouse (user: admin, password: qwerty, db: default, порт 9000 или 8123) и увидеть там таблицу со своими данными.

## Где что лежит

```
.
├── Dockerfile - кастомный докерфайл для Airflow
├── README.md
├── config - конфиг Airflow 
├── dags - даги
├── data.xlsx - файл для теста
├── docker-compose.yaml - докер-композ, который запускает ВСЕ
├── generate_xlsx.py - скрипт для генерации данных
├── internal - реализация flask-сервера
├── logs - логи Airflow
├── plugins - плагины Airfliow
├── requirements.txt - зависимости для работы скрипта по генерации
├── requirements_airflow.txt - зависимости для airflow
├── utils - всякие вспомоглательные штуки: константы и запросы
└── superset_data - это нам не нада :) данные для работы Superset
```

## Локальный запуск (ну а вдруг)

Поднять инфру можно, выполнив в корне

```shell
docker-compose up -d
```
