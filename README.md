# ETL производственной деятельности мясокомбината

## Обзор

ETL процесс для загрузки данных в базу данных clickhouse.

## Инфра

В данном проекте в докере настроен запуск следющих сервисов:
- Flask-сервер на Python для раздачи файлов
- Apache Airflow
- Clickhouse
- Apache Superset

## ETL

Каждую неделю в пятницу (по идеи) сотрудники какой-то организации загружают на Flask-сервер весь Excel файл. Далее из этого файла выбираются только записи за последнюю неделю. Они же перекладываются в clickhouse.

## Где что лежит

```
.
├── Dockerfile - кастомный докерфайл для Airflow
├── README.md
├── config - конфиг Airflow 
├── dags - даги
├── data.xlsx - файл для теста
├── docker-compose.yaml - докер-композ, который запускает ВСЕ
├── generate_xlsx.py - скрипт для генерации данных
├── internal - реализация flask-сервера
├── logs - логи Airflow
├── plugins - плагины Airfliow
├── requirements.txt - зависимости для работы скрипта по генерации
├── requirements_airflow.txt - зависимости для airflow
├── superset_data - это нам не нада :) данные для работы Superset
```
## Локальный запуск (ну а вдруг)

Поднять инфру можно, выполнив в корне

```shell
docker-compose up -d
```
